# German (de) scenario drafts — Stage 4, NOT wired in yet

Content-only. Nothing in `prisma/seed.ts`, the app, or any API route reads this
directory. It exists so the German Familie deck is versioned and reviewable
before the i18n infrastructure (routing, translation data model, seed
pipeline) is built.

- **`family/`** — Familie edition, 48 scored cards (12/12/12/12 H·A·C·K, 2
  diagnostic per trigger) + 2 wild cards. Generated by
  `scripts/gen-german-familie-draft.py` — edit that script and re-run it
  rather than hand-editing the JSON, so the H/A/C/K/diagnostic-count
  assertions keep holding.
- Voice decisions this deck assumes (approved by Tichi, 2026-09-10 and
  2026-09-11): **"du"** throughout; **"H.A.C.K."** kept untranslated as a
  brand term with German trigger glosses (H–Hetze, A–Autorität,
  C–Vertrautheit, K–Notbremse); the response framework **P.A.T. →
  "Anhalten · Abklären · Ansprechen"**.
- Scenarios are **culturally adapted, not translated** from the English
  deck — German-specific scam patterns (Schockanruf/falsche Polizei,
  Enkeltrick, "Hallo Mama"-Betrug, Finanzamt/ELSTER-Phishing,
  Kleinanzeigen, AnyDesk-Fernzugriff, Vignetten-/Maut-Phishing, etc.).
- `id` scheme (`family-de-fam-NN`, `lang: "de"` field) is a placeholder —
  the real scheme depends on the still-undecided translation data model
  (columns on `Scenario` vs. a `ScenarioTranslation` table vs. separate
  `edition: "family-de"` rows).
