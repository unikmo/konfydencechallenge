# German (de) scenario content — seeded into production

Wired into `prisma/seed.ts`: every JSON file here is upserted as a `Scenario`
row with `lang: "de"` on every production deploy, the same way
`data/scenarios/` seeds the English (`lang: "en"`) bank.

- **`family/`** — Familie edition, 48 scored cards (12/12/12/12 H·A·C·K, 2
  diagnostic per trigger) + 2 wild cards. Generated by
  `scripts/gen-german-familie-draft.py` — edit that script and re-run it
  rather than hand-editing the JSON, so the H/A/C/K/diagnostic-count
  assertions keep holding.
- Voice decisions this deck follows (approved by Tichi, 2026-09-10/11):
  **"du"** throughout; **"H.A.C.K."** kept untranslated as a brand term with
  German trigger glosses (H–Hetze, A–Autorität, C–Vertrautheit,
  K–Notbremse); the response framework **P.A.T. → "Anhalten · Abklären ·
  Ansprechen"**.
- Scenarios are **culturally adapted, not translated** from the English
  deck — German-specific scam patterns (Schockanruf/falsche Polizei,
  Enkeltrick, "Hallo Mama"-Betrug, Finanzamt/ELSTER-Phishing,
  Kleinanzeigen, AnyDesk-Fernzugriff, Vignetten-/Maut-Phishing, etc.).
- `id` scheme: `family-de-fam-NN` (mirrors the English `family-fam-NN`
  pattern, `-de-` marks the language). `externalId` stays globally unique
  across languages since every id is prefixed per language.
- A player's session is generated from one language pool at a time
  (`generateChallengeSessionPlan(edition, mode, userId, lang)`), so German
  and English "seen" history never mix even though they share one
  `ChallengeSession.edition` value.
